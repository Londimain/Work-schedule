# Табель учёта рабочего времени

Настольное приложение на Python + Kivy для ведения табеля учёта рабочего времени по форме Т-13 (упрощённой). Работает локально, без интернета и без базы данных — все данные хранятся в одном JSON-файле рядом с программой.

## Возможности

- **Справочник сотрудников** — отделы, должности, ФИО. Сотрудники группируются по отделам; поддерживается переименование и удаление.
- **Ведение табеля по месяцам** — ввод часов или буквенных кодов (В, О, Б, А, Р, Н, П, Т, Ц, У) в ячейку дня.
- **Автоматический расчёт итогов** по каждому сотруднику: явки, неявки по категориям, сумма часов, сверхурочные, ночные и праздничные.
- **Три настраиваемых признака должности** — «Ночные», «Сверхурочные», «Праздничные». Применяются ко всем сотрудникам с этой должностью автоматически. По умолчанию все три выключены.
- **Ручная корректировка** любой ячейки итогов с возможностью вернуться к авто-расчёту.
- **Навигация с клавиатуры** — Tab / Shift+Tab / стрелки перемещают фокус между ячейками, как в Excel. Введённое значение автоматически выделяется для быстрой перезаписи.
- **Копирование и вставка** — Ctrl+C / Ctrl+V работают как в Excel: для отдельной ячейки и для целого диапазона.
- **Выделение диапазона** — Shift+клик выделяет прямоугольный блок ячеек, клавиша Del очищает содержимое всего диапазона.
- **Индивидуальные подписи отделов** — у каждого отдела свой руководитель (пара «должность + ФИО»): для ЭНЕРГОСЛУЖБЫ — «Энергетик / Борщенков С.В.», для другого отдела — что угодно своё. Должности подписантов хранятся отдельно от должностей сотрудников.
- **Директор** — общее ФИО организации, редактируется прямо в верхней панели на вкладке «Рабочий персонал».
- **Защита удаления паролем** — удаление сотрудников, отделов, должностей и подписантов требует ввода пароля. Пароль по умолчанию — `admins` (настраивается в `config.py`).
- **Автосохранение** через 0,6 с после последнего изменения. Внешние правки `tabel_data.json` подхватываются без перезапуска.
- **Экспорт в Excel** (.xlsx) — готовый оформленный табель с шапкой, подсветкой выходных, строкой ИТОГО и двумя подписями (слева — руководитель отдела, справа — директор).
- **Иконка** окна и панели задач из `ico/tabel.ico` (Windows). Если файла нет — в заголовке появляется текстовый маркер `[T]`.
- **Сборка в один .exe** через готовый `main.spec` — с иконкой, шрифтом и openpyxl внутри.

## Требования

- **Python** 3.9 или новее
- **ОС**: Windows / Linux / macOS (иконка панели задач ставится через WinAPI — работает только на Windows)
- **Шрифт Arial** (на Windows уже есть; на Linux/macOS автоматически используется Roboto)
- **Зависимости**:
  - `kivy >= 2.2`
  - `openpyxl >= 3.0` (для экспорта в Excel)
  - `pyinstaller >= 6.0` (только для сборки `.exe`)

Установка зависимостей:

```bash
pip install kivy openpyxl pyinstaller
```

## Сборка в .exe

В репозитории уже есть готовый `main.spec` — PyInstaller-конфиг с иконкой, шрифтом и собранным openpyxl. Пересобирать `.spec` не нужно.

### Команды для сборки (PowerShell)

```powershell
Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force __pycache__ -ErrorAction SilentlyContinue
python -m PyInstaller --clean --noconfirm main.spec
```

### Результат

- `dist/main/main.exe` — исполняемый файл
- `dist/main/_internal/` — служебные файлы (DLL Kivy, шрифты, `ico/tabel.ico`, openpyxl)

Переносите на другой компьютер **всю папку** `dist/main`.

### Что внутри `main.spec`

- `datas = [('ico/tabel.ico', 'ico')]` — файл иконки попадает в бандл, чтобы `apply_app_icon()` нашёл его во время работы.
- `collect_all('openpyxl')` — подтягивает все модули, данные и бинарники openpyxl, чтобы экспорт в Excel работал в собранном .exe.
- `icon=['ico/tabel.ico']` — иконка самого `.exe` (Проводник и панель задач).
- `console=False` — запуск без консольного окна.

## Как пользоваться

### Вкладка «Рабочий персонал»

1. **Добавьте отделы** кнопкой «+ Отдел». У каждого отдела обязательно должны быть:
   - Название отдела,
   - Должность руководителя (например «Энергетик», «Начальник цеха»),
   - ФИО руководителя.
   
   Должность можно ввести вручную или выбрать из уже сохранённых кнопкой **«Выбрать»**. Если ввести новое название — оно запомнится и появится в списке при следующем создании отдела.

2. **Добавьте должности сотрудников** кнопкой «+ Должность» (например «электромонтер», «оператор котельной»). Для каждой должности задаются три признака:
   - **Ночные** — считаются ночные часы по шкале 4→1, 5→2, 6→3, 7–11→6.
   - **Сверхурочные** — считаются часы сверх нормы (число рабочих дней × 8).
   - **Праздничные** — часы в выходные/праздники идут в отдельную колонку.

3. **Добавьте сотрудников** кнопкой «+ Добавить сотрудника»: ФИО, отдел, должность. Галочка «В таблицу» определяет, попадёт ли сотрудник в табель.

> Одновременно табель может вестись **только по одному отделу**. При попытке включить сотрудника другого отдела программа предупредит.

### Вкладка «Табель»

1. Выберите **месяц** и **год** вверху.
2. В ячейки дней вводите **число часов** (например `8`, `7.5`) или **буквенный код**:
   - `В` — выходной
   - `О` — трудовой отпуск
   - `Б` — больничный
   - `А` — отпуск за свой счёт
   - `Р` — отпуск по родам
   - `Н` — прочие неявки
   - `П` — прогул
   - `Т` — текущий простой
   - `Ц` — целосменный простой
   - `У` — опоздание
3. Итоги справа пересчитываются **автоматически**. Любую ячейку итогов можно отредактировать вручную — она перестанет пересчитываться. Кнопка «Сбросить правки» вернёт авто-расчёт.

### Вкладка «Отчёт и печать»

1. Выберите месяц и год.
2. Кнопка **«Сохранить в Excel»** формирует файл `tabel_ГОД-МЕСЯЦ.xlsx` в подпапке `Табель/<Отдел>/<Год>/` рядом с программой и сразу открывает его в Excel.
3. В файле — шапка, подсветка выходных/праздников, строка ИТОГО и **две подписи**:
   - слева — «Руководитель:» + должность и ФИО подписанта того отдела, по которому ведётся табель;
   - справа — «Утверждение:» + «Директор» и его ФИО.

### Поле «Директор» в верхней панели

Появляется на вкладке «Рабочий персонал» справа от вкладок. Редактируется в один клик, сохраняется автоматически через 0,5 с.

### Удаление записей

Все кнопки **«Удалить»** (сотрудника, отдела, должности сотрудника, должности подписанта) открывают диалог с вводом **пароля**. Меняется в `config.py`:

```python
DELETE_PASSWORD = "******"
```

При неверном пароле появится сообщение «Неверный пароль», поле очистится, диалог останется открытым.

## Горячие клавиши

Работают в табеле, когда фокус стоит в ячейке:

| Клавиши | Действие |
|---|---|
| `Tab` / `Shift+Tab` | Переход к следующей / предыдущей ячейке (дни → итоги → следующий сотрудник) |
| `←` / `→` | Курсор внутри ячейки; на краю — переход к соседней |
| `↑` / `↓` | Тот же столбец, соседняя строка |
| `Ctrl+C` | Копировать значение ячейки или выделенный диапазон |
| `Ctrl+V` | Вставить значение в ячейку или диапазон от активной ячейки / якоря выделения |
| `Del` | Очистить активную ячейку или всё выделение |
| `Shift + клик` | Выделить прямоугольный диапазон ячеек |

При переходе фокуса текст автоматически выделяется — можно сразу набирать новое значение. Вставка работает с TSV-форматом: можно копировать данные из Excel и вставлять в табель.

## Формат данных

Все данные хранятся в `tabel_data.json` рядом с программой (или `.exe`):

```json
{
  "employees": [
    {
      "id": "emp_...",
      "name": "Ильенков С.М.",
      "position": "электромонтер",
      "department": "ЭНЕРГОСЛУЖБА",
      "show_in_timesheet": true
    }
  ],
  "timesheets": {
    "2026-10": {
      "emp_...": { "6": "4", "19": "2" }
    }
  },
  "positions": ["электромонтер", "оператор котельной"],
  "night_flags":    { "электромонтер": false, "оператор котельной": true },
  "overtime_flags": { "электромонтер": true,  "оператор котельной": false },
  "holiday_flags":  { "электромонтер": true,  "оператор котельной": false },
  "departments": ["ЭНЕРГОСЛУЖБА"],
  "signer_positions": ["Энергетик", "Начальник цеха"],
  "department_signer": {
    "ЭНЕРГОСЛУЖБА": {
      "position": "Энергетик",
      "name": "Борщенков С.В."
    }
  },
  "organization": "ОАО \"Компания \"МогНат\"",
  "director_name": "С. А. Авчинников",
  "result_overrides": { "2026-10": {} }
}
```

**Ключи:**
- `positions` — должности сотрудников.
- `signer_positions` — должности подписантов отделов (отдельный список).
- `department_signer` — для каждого отдела — его руководитель (`position`, `name`).
- `night_flags` / `overtime_flags` / `holiday_flags` — признаки для должностей сотрудников.
- `result_overrides` — ручные правки итогов по месяцам.

## Резервное копирование

Просто **скопируйте файл `tabel_data.json`** в надёжное место. Это весь банк данных приложения.

Файл обновляется автоматически; если открыть его в текстовом редакторе и сохранить, работающая программа подхватит изменения в течение 2–3 секунд.

## Известные ограничения

- Одновременно табель ведётся **только по одному отделу**. Нельзя включить в табель сотрудников из разных отделов.
- Иконка панели задач через WinAPI — **только Windows**. На Linux/macOS устанавливается иконка окна через Kivy, системная иконка панели задач остаётся стандартной.
- Для экспорта в Excel нужен `openpyxl`. В собранном .exe он уже внутри; при запуске из исходников установите `pip install openpyxl`.
- Шрифт по умолчанию — **Arial** (Windows). На Linux/macOS при отсутствии Arial подхватывается Roboto.
