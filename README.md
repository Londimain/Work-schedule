# Табель учёта рабочего времени

Настольное приложение на Python / Kivy для ведения табеля учёта
рабочего времени по форме Т-13 (упрощённой). Работает локально,
поддерживает совместную работу нескольких компьютеров с общим
файлом данных.

## Возможности

- **Ежедневный учёт** явок, неявок и отработанных часов.
- **Автоматический расчёт** итогов по каждому сотруднику за месяц:
  явки, неявки по категориям, сумма часов, сверхурочные, ночные
  и праздничные.
- **Списочная и среднесписочная численность** — считается сама.
- **Признаки должностей** «Ночные», «Сверхурочные» и «Без вых.» —
  включают соответствующий расчёт для всех сотрудников
  этой должности.
- **Гибкий ввод часов**:
  - простое число — `8`, `7,5`, `4`;
  - со сменой — `8//1`, `8//2`, `12//2`;
  - с пометкой «д» — `8д`, `7,5д` (явка без ночных).
- **Коды неявок**: `В`, `О`, `Б`, `А`, `Р`, `Н`, `ДМ`, `П`, `Т`, `Ц`, `У`.
- **Ручная корректировка итогов** с возможностью сброса к авто-расчёту.
- **Навигация как в Excel**: Tab / Shift+Tab, стрелки, Ctrl+C / Ctrl+V,
  Shift+клик для выделения диапазона, Del для очистки.
- **Перестановка** сотрудников внутри отдела и целых отделов —
  через контекстное меню (правый клик).
- **Автосохранение** через 0,6 с после последнего изменения.
- **Смена темы оформления** (5 встроенных цветовых схем) с возможностью
  мгновенного перезапуска для применения.
- **Экспорт в Excel** (`.xlsx`) с готовым оформлением: умная шапка 
  с автоматическим объединением ячеек (текст не наезжает и не обрезается), 
  подсветка выходных/праздников, строка ИТОГО, подписи.
- **Совместная работа**: несколько компьютеров могут работать
  с общим файлом `tabel_data.json`, при этом у каждого —
  свои локальные настройки (выбор сотрудников, порядок и тема).
- **Защита удаления паролем**.

## Требования

Для запуска из исходного кода (скрипта):
- Python **3.8+**
- **Kivy** 2.0+
- **openpyxl** — только для экспорта в Excel

Для сборки в `.exe`:
- **PyInstaller** (рекомендуется версия 4.10 для совместимости с Windows 7)
- **pywin32**
- **kivy_deps.sdl2** и **kivy_deps.angle** — для правильной работы графики на разных ПК.
