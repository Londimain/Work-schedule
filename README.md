# Табель учёта рабочего времени

Настольное приложение на Python / Kivy для ведения табеля учёта
рабочего времени по форме Т-13 (упрощённой). Работает локально,
поддерживает совместную работу нескольких компьютеров с общим
файлом данных.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Kivy](https://img.shields.io/badge/Kivy-2.0%2B-green)

## Возможности

- **Ежедневный учёт** явок, неявок и отработанных часов.
- **Автоматический расчёт** итогов по каждому сотруднику за месяц:
  явки, неявки по категориям, сумма часов, сверхурочные, ночные
  и праздничные.
- **Списочная и среднесписочная численность** — считается сама.
- **Признаки должностей** «Ночные» и «Сверхурочные» —
  включают соответствующий расчёт для всех сотрудников
  этой должности.
- **Гибкий ввод часов**:
  - простое число — `8`, `7,5`, `4`;
  - со сменой — `8//1`, `8//2`, `12//2`;
  - с пометкой «д» — `8д`, `7,5д` (явка без ночных).
- **Коды неявок**: `В`, `О`, `Б`, `А`, `Р`, `Н`, `ДМ`, `П`, `Т`, `Ц`, `У`.
- **Ручная корректировка итогов** с возможностью сброса к авто-расчёту.
- **Навигация как в Excel**: Tab / Shift+Tab, стрелки, Ctrl+C / Ctrl+V,
  Shift+клик для выделения диапазона, Del для очистки.
- **Перестановка** сотрудников внутри отдела и целых отделов —
  через контекстное меню (правый клик).
- **Автосохранение** через 0,6 с после последнего изменения.
- **Экспорт в Excel** (`.xlsx`) с готовым оформлением: шапка,
  подсветка выходных/праздников, строка ИТОГО, подписи.
- **Совместная работа**: несколько компьютеров могут работать
  с общим файлом `tabel_data.json`, при этом у каждого —
  свои локальные настройки (выбор сотрудников и порядок).
- **Защита удаления паролем**.

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Londimain/Work-schedule.git
cd Work-schedule

# 2. Установить зависимости
pip install kivy openpyxl

# 3. Запустить
python main.py
```

### Сборка в .exe (Windows)

```bash
pip install pyinstaller

pyinstaller --name Tabel \
            --windowed \
            --onefile \
            --icon=ico/tabel.ico \
            --add-data "ico;ico" \
            main.py
```

Готовый файл появится в `dist/Tabel.exe`.

## Быстрый старт

1. **Заполните справочник** на вкладке «Рабочий персонал»:
   - добавьте отдел (кнопка «+ Отдел»);
   - добавьте должности (кнопка «+ Должность»);
   - добавьте сотрудников (кнопка «+ Добавить сотрудника»).
2. **Отметьте сотрудников** галочкой «В таблицу» — они появятся
   на вкладке «Табель».
3. **Выберите месяц и год** на вкладке «Табель» и начинайте
   вводить часы и коды.
4. По окончании месяца откройте вкладку «Отчёт и печать» —
   проверьте сводку и нажмите «Сохранить в Excel».

## Форматы ввода в табеле

### Коды

| Код  |              Расшифровка               |    Колонка итогов    |
|------|----------------------------------------|----------------------|
| `В`  | выходной                               | Выходной             |
| `О`  | трудовой отпуск                        | Трудовой отпуск      |
| `Б`  | больничный                             | Болезнь              |
| `А`  | отпуск за свой счёт                    | Отпуск без з/п       |
| `Р`  | отпуск по родам                        | Отп. по родам        |
| `Н`  | прочие неявки                          | Прочие неявки        |
| `ДМ` | прочие неявки, день матери             | Прочие неявки        |
| `П`  | прогул                                 | Прогул               |
| `Т`  | текущий простой                        | Текущий простой      |
| `Ц`  | целосменный простой                    | Целосмен. простой    |
| `У`  | опоздание                              | Опоздания            |

Регистр не важен: `дм`, `Дм`, `ДМ` — одно и то же.

### Часы

| Ввод      | Явки | Всего | Ночные | Праздничные        |
|-----------|------|-------|--------|--------------------|
| `8`       | +1   | +8    | по шкале | +8 в вых./праздн. |
| `7,5`     | +1   | +7,5  | по шкале | +7,5 в вых./праздн. |
| `8//1`    | +1   | +8    | **0**  | +8 в вых./праздн. |
| `8//2`    | +1   | +8    | +1     | +8 в вых./праздн. |
| `12//2`   | +1   | +12   | +8     | +12 в вых./праздн. |
| `8д`      | +1   | +8    | **0**  | +8 в вых./праздн. |
| `7,5д`    | +1   | +7,5  | **0**  | +7,5 в вых./праздн. |

**Шкала ночных для второй смены:**

```
 8 → 1     9 → 2    10 → 3    11 → 4
12 → 8    13 → 8    14 → 8    15 → 8
```

Для первой смены (`//1`) ночных всегда **0**, независимо от часов.

**Без указания смены** ночные считаются по старой шкале:
`4 → 1, 5 → 2, 6 → 3, 7–11 → 6`, иначе `0`.

**Пометка «д»** (большая или малая буква) блокирует ночные —
явка и «Всего» посчитаются как для числа, а ночные — нет.

### Сверхурочные

Считаются только по часам, отработанным в рабочие дни:

```
сверхурочные = (всего_часов − праздничные) − норма
норма = рабочих_дней_в_месяце × 8
```

Часы, отработанные в выходные и праздники, идут в «праздничные»
и **не** участвуют в расчёте сверхурочных (защита от двойной оплаты).

## Навигация с клавиатуры

| Клавиши            | Действие                                        |
|--------------------|-------------------------------------------------|
| `Tab` / `Shift+Tab`| следующая / предыдущая ячейка                   |
| `←` / `→`          | курсор в ячейке; на краю — переход к соседней   |
| `↑` / `↓`          | тот же столбец, соседний сотрудник              |
| `Ctrl+C` / `Ctrl+V`| копировать / вставить (в т.ч. диапазон TSV)     |
| `Shift + клик`     | выделить диапазон ячеек                         |
| `Del`              | очистить выделенный диапазон или активную ячейку|

Первый печатный символ после получения фокуса заменяет всё
содержимое ячейки (как в Excel).

- Windows: `%APPDATA%\TabelApp\local.json`
- Linux:   `~/.config/TabelApp/local.json`

## Данные и совместная работа

### `tabel_data.json` — общий файл

Хранит:

- список сотрудников, отделов, должностей;
- часы по каждому сотруднику за каждый месяц;
- признаки «Ночные» / «Сверхурочные» по должностям;
- организацию, ФИО директора, подписантов отделов;
- ручные правки итогов.

Файл можно разместить в общей папке (сетевой диск) — тогда
несколько компьютеров смогут работать с одними и теми же данными.
Изменения подхватываются автоматически в течение нескольких секунд.

### `local.json` — локальные настройки

Хранит только то, что должно быть **разным** на разных машинах:

- выбор галочек «В таблицу» (какие сотрудники попадают в табель);
- порядок отделов и сотрудников (перестановки правым кликом).

Это позволяет на одной машине вести табель по отделу
«ЭНЕРГОСЛУЖБА», а на другой — по «КОТЕЛЬНОЙ», пользуясь
общим справочником сотрудников.

### Резервная копия

Просто скопируйте `tabel_data.json` в надёжное место.
Файл `local.json` при этом можно не копировать — он
привязан к конкретному компьютеру.

## Ограничения одновременной работы

На каждом компьютере табель ведётся **только по одному отделу**.
При попытке включить сотрудника другого отдела программа
предупредит и не даст этого сделать, пока не будут сняты
галочки «В таблицу» у сотрудников текущего отдела.

Это гарантирует, что разные машины не испортят данные друг друга.

## Пароль на удаление

Все операции удаления (сотрудники, отделы, должности) защищены
паролем. По умолчанию:

```python
DELETE_PASSWORD = "admins"    # config.py
```

Пароль можно изменить в `config.py`.

## Экспорт в Excel

Кнопка «Сохранить в Excel» на вкладке «Отчёт и печать» формирует
файл вида:

```
Табель/<Отдел>/<Год>/tabel_<ГГГГ-ММ>.xlsx
```

Файл содержит:

- заголовок и шапку с числами месяца и днями недели;
- подсветку выходных (розовый) и праздников (жёлтый);
- строки сотрудников с часами и итогами;
- строку ИТОГО;
- списочную и среднесписочную численность;
- подписи руководителя отдела и директора.

Для экспорта требуется библиотека `openpyxl`.
