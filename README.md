Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue

## Как пользоваться

### Вкладка «Рабочий персонал»

1. **Добавьте отделы** кнопкой «+ Отдел». У каждого отдела обязательно должны быть Название, Должность руководителя и ФИО руководителя.

2. **Добавьте должности сотрудников** кнопкой «+ Должность» (например «электромонтер»). Для каждой должности задаются два признака:
   - **Ночные** — считаются ночные часы по шкале 4→1, 5→2, 6→3, 7–11→6.
   - **Сверхурочные** — считаются часы сверх нормы (число рабочих дней × 8).

3. **Добавьте сотрудников** кнопкой «+ Добавить сотрудника»: ФИО, отдел, должность. В карточке сотрудника есть две галочки:
   - **На контракте** — учитывается при расчёте списочной численности.
   - **В таблицу** — определяет, попадёт ли сотрудник в табель **на этом компьютере**.

> **Важно про галочку «В таблицу».** Выбор галочек **хранится локально** на каждом компьютере (`local.json`) и **не синхронизируется**. Одновременно табель на конкретном компьютере может вестись **только по одному отделу**.

### Вкладка «Табель»

1. Выберите **месяц** и **год** вверху.
2. В ячейки дней вводите **число часов** (например `8`, `7.5`) или **буквенный код** (В, О, Б, А, Р, Н, П, Т, Ц, У).
3. **Особенности расчёта выходных:** Если вы вводите часы (например, 8) в субботу или праздник, они автоматически:
   - идут в колонку «праздничные»;
   - добавляются к «Всего» часов;
   - добавляют +1 к «Факт. работы» (явки).
4. Итоги справа пересчитываются автоматически. Их можно корректировать вручную.

### Вкладка «Отчёт и печать»

1. Выберите месяц и год.
2. Кнопка **«Сохранить в Excel»** формирует файл `tabel_ГОД-МЕСЯЦ.xlsx` и открывает его.
3. В файле помимо таблицы и подписей выводятся **Списочная** и **Среднесписочная** численность.

| `Tab` / `Shift+Tab` | Переход к следующей / предыдущей ячейке |
| `←` / `→` | Курсор внутри ячейки; на краю — переход к соседней |
| `↑` / `↓` | Тот же столбец, соседняя строка |
| `Ctrl+C` / `Ctrl+V` | Копировать / вставить значение или диапазон |
| `Del` | Очистить активную ячейку или всё выделение |
| `Shift + клик` | Выделить прямоугольный диапазон ячеек |

### Локальный файл `local.json`

## Совместная работа на нескольких компьютерах

Общий файл `tabel_data.json` может лежать на сетевом диске. Галочки «В таблицу» и порядок строк при этом остаются локальными для каждой машины. Это позволяет на одной машине вести табель по одному отделу, а на другой — по другому.

## Резервное копирование

**Основные данные** — скопируйте файл `tabel_data.json`.

**Локальные настройки** — файл `local.json` (обычно не требует резервирования).

---

## Известные ограничения

- Одновременно табель на **конкретном компьютере** ведётся **только по одному отделу**.
- Иконка панели задач через WinAPI — **только Windows**.
- Для экспорта в Excel нужен `openpyxl`.
