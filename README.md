# Табель учёта рабочего времени

Настольное приложение на Python / Kivy для ведения табеля учёта
рабочего времени по форме Т-13 (упрощённой). Работает локально
и поддерживает **совместную работу нескольких компьютеров**
через общий файл данных с автоматической синхронизацией.

## Возможности

- **Ежедневный учёт** явок, неявок и отработанных часов.
- **Автоматический расчёт итогов** по каждому сотруднику за месяц:
  явки, неявки по категориям, сумма часов, сверхурочные, ночные
  и праздничные.
- **Списочная и среднесписочная численность** — считается автоматически.
- **Признаки должностей**: «Ночные», «Сверхурочные», «Без вых.» —
  включают соответствующий расчёт для всех сотрудников этой должности.
- **Гибкий ввод часов**: обычные числа (`8`, `7,5`), смены (`8//1`, `8//2`, `12//2`), пометка «д» (`8д` — без ночных).
- **Большой набор кодов неявок**: `В`, `О`, `Б`, `А`, `РО`, `К`, `МК`, `СР`, `Р`, `ТО`, `КД`, `Н`, `ДМ`, `П`, `Т`, `Ц`, `У`.
- **Эффект наведения мыши**: строки таблиц и кнопки в окнах «Рабочий персонал», «Должности», «Отделы» и «Подписанты» мягко подсвечиваются при наведении, что делает работу с интерфейсом комфортнее.
- **Плавное обновление табеля**: при смене месяца, года или синхронизации с другими ПК таблица обновляется без мерцания и скачков интерфейса.
- **Адаптивный интерфейс**: кнопки верхней панели сжимаются, а текст аккуратно обрезается при сужении окна. Ширина колонок подстраивается под введённые данные.
- **Свой набор итогов**: кнопка «Настроить итоги» позволяет каждому пользователю выбрать, какие колонки отображать в таблице и Excel (настройка сохраняется локально).
- **Скрытие/отображение итогов**: кнопка «Скрыть итоги» позволяет развернуть таблицу на весь экран.
- **Ручная корректировка итогов** с возможностью сброса к авто-расчёту.
- **Визуальное выделение**: отдел, в котором хотя бы у одного сотрудника стоит галочка «В таблицу», подсвечивается ярким оранжевым цветом.
- **Навигация как в Excel**: `Tab` / `Shift+Tab`, стрелки, `Ctrl+C` / `Ctrl+V`, `Shift+клик` для выделения диапазона, `Del` для очистки.
- **Перестановка** сотрудников внутри отдела и целых отделов — через контекстное меню (правый клик).
- **Сворачивание отделов**: клик по полосе отдела скрывает/показывает сотрудников. Состояние запоминается.
- **Автосохранение** через 0,6 с после последнего изменения.
- **Смена темы оформления** (5 встроенных цветовых схем).
- **Дополнительные подписанты**: произвольные лица для подписи в Excel, с выбором из общей базы.
- **Экспорт в Excel** (`.xlsx`) с готовым оформлением: умная шапка, автоширина, подсветка выходных/праздников, строка ИТОГО, подписи.
- **Совместная работа** с автоматическим обновлением данных и открытых окон между компьютерами (см. раздел «Совместная работа»).
- **Защита удаления** и изменения признаков должностей паролем.
- **Защита от повторного запуска** exe (на Windows — по Mutex).

## Требования

Для запуска из исходного кода (скрипта):

- Python **3.8+**
- Зависимости из `requirements.txt` (см. ниже)

Для сборки в `.exe` (Windows):

- **PyInstaller** (рекомендуется версия 4.10 для совместимости с Windows 7)
- **pywin32**
- **kivy_deps.sdl2** и **kivy_deps.angle** — для правильной работы графики на разных ПК

## Сборка в `.exe` (Windows)

Сборка Kivy-приложений имеет свои особенности. Вам потребуется специальный
конфигурационный файл `main.spec`, так как обычная команда `pyinstaller main.py`
не включит в себя библиотеки Kivy, SDL2 и ANGLE, из-за чего программа вылетит
с ошибкой.

### Шаг 1. Установка библиотек для сборки

В активированном виртуальном окружении выполните:

```cmd
pip install pywin32==225
pip install pyinstaller==4.10
pip install kivy_deps.sdl2 kivy_deps.angle
```

*(Примечание: PyInstaller 4.10 выбран как самая стабильная версия для Windows 7.
На Windows 10/11 можно использовать и более новые версии).*

### Шаг 2. Файл `main.spec`

Готовый `main.spec` уже лежит в корне проекта. Если его нет — создайте
со следующим содержимым:

```python
# -*- mode: python ; coding: utf-8 -*-
import os
import glob
from kivy import kivy_data_dir
from PyInstaller.utils.hooks import collect_submodules
from kivy_deps import sdl2, angle

# 1. Бинарники: opengl32.dll + DLL из sdl2 и angle
kivy_bins = []
if os.path.isfile('opengl32.dll'):
    kivy_bins.append(('opengl32.dll', '.'))

def _expand(dep_list):
    out = []
    for dep in dep_list:
        if isinstance(dep, (tuple, list)) and len(dep) == 2:
            src, dest = dep
        else:
            src, dest = dep, '.'
        if os.path.isdir(src):
            for f in glob.glob(os.path.join(src, '*')):
                out.append((f, dest))
        elif any(ch in src for ch in '*?['):
            for f in glob.glob(src):
                out.append((f, dest))
        elif os.path.isfile(src):
            out.append((src, dest))
    return out

kivy_bins += _expand(sdl2.dep_bins)
kivy_bins += _expand(angle.dep_bins)

# 2. Данные Kivy и иконки
datas = [(kivy_data_dir, 'kivy/data')]
datas += [('ico', 'ico')]

# 3. Скрытые импорты
hiddenimports = collect_submodules('kivy', filter=lambda name: not name.startswith('kivy.garden'))
hiddenimports += [
    'openpyxl',
    'openpyxl.styles',
    'openpyxl.utils',
    'filelock',
    'filelock._unix',
    'filelock._windows',
    'urllib.request',
    'urllib.error',
    'ssl',
    'http.client'
]

block_cipher = None

a = Analysis(
    ['main.py'],
    pathex=[],
    binaries=kivy_bins,
    datas=datas,
    hiddenimports=hiddenimports,
    hookspath=[],
    hooksconfig={},
    runtime_hooks=[],
    excludes=['numpy', 'pandas', 'matplotlib', 'scipy', 'tkinter',
              'PIL', 'wx', 'gi', 'gst'],
    win_no_prefer_redirects=False,
    win_private_assemblies=False,
    cipher=block_cipher,
    noarchive=False,
)
pyz = PYZ(a.pure, a.zipped_data, cipher=block_cipher)

exe = EXE(
    pyz, a.scripts, a.binaries, a.zipfiles, a.datas, [],
    name='Work schedule',
    debug=False,
    bootloader_ignore_signals=False,
    strip=False,
    upx=False,
    upx_exclude=[],
    runtime_tmpdir=None,
    console=False,
    disable_windowed_traceback=False,
    argv_emulation=False,
    target_arch=None,
    codesign_identity=None,
    entitlements_file=None,
    icon='ico/tabel.ico',
    version='version_info.txt',
)
```

### Шаг 3. Запуск сборки

Перед сборкой задайте переменные окружения, чтобы Kivy использовал
DirectX (ANGLE). Это критически важно для работы на Windows 7 и в VirtualBox.

```cmd
set KIVY_GL_BACKEND=angle_sdl2
python -m PyInstaller --clean --noconfirm main.spec
```

Готовый файл `Work schedule.exe` появится в папке `dist`.

## Быстрый старт

1. **Заполните справочник** на вкладке «Рабочий персонал»:
   - добавьте отдел (кнопка «+ Отдел»);
   - добавьте должности (кнопка «+ Должность»);
   - добавьте сотрудников (кнопка «+ Добавить сотрудника»).
2. **Отметьте сотрудников** галочкой «В таблицу» — они появятся на вкладке «Табель».
3. **Выберите месяц и год** на вкладке «Табель» и начинайте вводить часы и коды.
4. По окончании месяца откройте вкладку «Отчёт и печать» — проверьте сводку,
   настройте при необходимости дополнительные подписанты и нажмите «Сохранить в Excel».

## Форматы ввода в табеле

### Коды неявок

| Код  |              Расшифровка               |    Колонка итогов    |
|------|----------------------------------------|----------------------|
| `В`  | выходной                               | Выходной             |
| `О`  | трудовой отпуск                        | Трудовой отпуск      |
| `Б`  | больничный                             | Болезнь              |
| `А`  | отпуск за свой счёт                    | Отпуск без з/п       |
| `РО` | отпуск по родам                        | Отп. по родам        |
| `К`  | командировка                           | Командировка         |
| `МК` | медицинская комиссия                   | Мед. комиссия        |
| `СР` | оплата по среднему                     | Оплата по среднему   |
| `Р`  | ремонт                                 | Ремонт               |
| `ТО` | техническое обслуживание               | Тех. обслуживание    |
| `КД` | коллективный договор                   | Кол. договор         |
| `Н`  | прочие неявки                          | Прочие неявки        |
| `ДМ` | прочие неявки, день матери             | Прочие неявки        |
| `П`  | прогул                                 | Прогул               |
| `Т`  | текущий простой                        | Текущий простой      |
| `Ц`  | целосменный простой                    | Целосмен. простой    |
| `У`  | опоздание                              | Опоздания            |

Регистр не важен: `дм`, `Дм`, `ДМ` — одно и то же.

### Часы и смены

| Ввод      | Явки | Всего | Ночные | Праздничные        |
|-----------|------|-------|--------|--------------------|
| `8`       | +1   | +8    | **0**  | +8 в вых./праздн. |
| `7,5`     | +1   | +7,5  | по шкале | +7,5 в вых./праздн. |
| `8//1`    | +1   | +8    | **0**  | +8 в вых./праздн. |
| `8//2`    | +1   | +8    | +1     | +8 в вых./праздн. |
| `12//2`   | +1   | +12   | +8     | +12 в вых./праздн. |
| `8д`      | +1   | +8    | **0**  | +8 в вых./праздн. |

**Шкала ночных для второй смены:**
```
 8 → 1     9 → 2    10 → 3    11 → 4
12 → 8    13 → 8    14 → 8    15 → 8
```
Для первой смены (`//1`) ночных всегда **0**, независимо от часов.

**Без указания смены** ночные считаются по старой шкале:
`4 → 1, 5 → 2, 6 → 3, 7–11 → 6`, иначе `0`. Обычная цифра `8` ночных не даёт (как и `8д`).

### Сверхурочные

Считаются только по часам, отработанным в рабочие дни:
```
сверхурочные = (всего_часов − праздничные) − норма
норма = рабочих_дней_в_месяце × 8
```
Часы, отработанные в выходные и праздники, идут в «праздничные»
и **не** участвуют в расчёте сверхурочных (защита от двойной оплаты).

## Навигация и Горячие клавиши

| Клавиши            | Действие                                        |
|--------------------|-------------------------------------------------|
| `Tab` / `Shift+Tab`| следующая / предыдущая ячейка                   |
| `←` / `→`          | курсор в ячейке; на краю — переход к соседней   |
| `↑` / `↓`          | тот же столбец, соседний сотрудник              |
| `Ctrl+C` / `Ctrl+V`| копировать / вставить (в т.ч. диапазон TSV)     |
| `Shift + клик`     | выделить диапазон ячеек                         |
| `Del`              | очистить выделенный диапазон или активную ячейку|

Первый печатный символ после получения фокуса заменяет всё
содержимое ячейки (как в Excel). Колесико мыши над днями месяца прокручивает
их строго по горизонтали, не сбивая список сотрудников.

## Ручные правки итогов

Любую ячейку в колонках итогов можно поправить вручную — прямо в таблице.
Применяется автоматически при выходе из ячейки (или по `Enter`).

- **Кнопка «Применить правки»** — фиксирует все правки, сделанные в текущем месяце.
- **Кнопка «Сбросить правки»** — удаляет все ручные правки по текущему месяцу и возвращает авто-расчёт.

Ручные правки сохраняются в общем файле (`result_overrides`) и подхватываются другими ПК.

## Совместная работа

Приложение можно использовать на нескольких компьютерах с общим файлом
`tabel_data.json` (например, на сетевом диске).

### Что синхронизируется автоматически (раз в ~3 секунды)

- Справочник сотрудников: состав, ФИО, должности, порядок.
- Отделы и их порядок.
- Список должностей и признаки «Ночные», «Сверхурочные», «Без вых.».
- Все дневные часы и коды неявок.
- Ручные правки итогов (`result_overrides`).
- Временные сотрудники (привязаны к месяцу и отделу).
- Общая база дополнительных подписантов (`shared_signers`).

### Живое обновление открытых окон

Если у вас открыт один из следующих попапов, он **обновится сам**, без перезапуска:

| Открытое окно | Что обновится |
|---|---|
| «Сотрудник» (добавить/изменить) | выпадающие списки **Отдел** и **Должность** |
| «Должности» | весь список |
| «Отделы» | весь список |
| «Изменить отдел» / «Новый отдел» | поле **Должность** (при переименовании `signer_positions`) |
| «Временные сотрудники» | список добавленных сотрудников |
| «Выбор сотрудника/должности» (из «Временных») | список в окне выбора |
| «Доп. подписанты» | весь список |
| «Выбор подписанта из базы» | список кандидатов |

Если пользователь **прямо сейчас редактирует поле**, автообновление
в это поле не пишет — только в `.values` выпадающих списков.
При переименовании (когда в новом списке ровно одно новое значение)
поле подставляется автоматически.

### Что НЕ синхронизируется (правильно)

- Открытый диалог **редактирования** сотрудника/отдела/подписанта — там
  пользователь печатает, автообновление не перебивает ввод.
- Окно «Настроить итоги» — это **локальная** настройка.
- Окно «Тема» — **локальная** настройка.

### Ограничения

На каждом компьютере табель ведётся **только по одному отделу**.
При попытке включить сотрудника другого отдела программа предупредит
и не даст этого сделать, пока не будут сняты галочки «В таблицу»
у сотрудников текущего отдела. Активный отдел подсвечивается
**ярким оранжевым цветом** (не зависит от выбранной темы).

## Данные

### `tabel_data.json` — общий файл

Хранит:

- Список сотрудников.
- Часы за каждый месяц.
- Настройки должностей.
- Подписи и ручные правки.
- **Общую базу дополнительных подписантов** (`shared_signers`).

Файл можно разместить в общей папке (сетевой диск) — тогда несколько
компьютеров работают с одними данными. Запись защищена `filelock`,
а сохраняется атомарно (`.tmp` + `os.replace`).

Путь: **рядом с программой** (`BASE_DIR/tabel_data.json`).

### `local.json` — локальные настройки

Хранит то, что должно быть **разным** на разных машинах:

- Тема оформления.
- Галочки «В таблицу» и порядок отделов/сотрудников.
- Свёрнутые/развёрнутые отделы.
- **Какие колонки итогов отображать** («Настроить итоги»).
- Скрыты или показаны итоги в табеле целиком.
- **Локальный список выбранных подписантов для печати** (именно они попадают в ваш Excel).

Файл хранится **вне** папки программы:

- Windows: `%APPDATA%\TabelApp\local.json`
- Linux:   `~/.config/TabelApp/local.json`

### Резервная копия

Просто скопируйте `tabel_data.json` в надёжное место.
Файл `local.json` копировать не обязательно — он привязан к конкретному компьютеру.

## Пароль на удаление

Все операции удаления (сотрудники, отделы, должности, подписанты),
а также изменение признаков должностей (Ночные, Сверхурочные, Без вых.)
защищены паролем. По умолчанию:

```python
DELETE_PASSWORD = "****"    # config.py
```

Пароль можно изменить в `config.py`.

## Дополнительные подписанты

Кнопка «Доп. подписанты» на вкладке «Отчёт и печать» позволяет добавлять
произвольных лиц для подписи в Excel.

- **Список для печати (локальный)**: подписанты, отмеченные галочкой,
  сохраняются только на вашем компьютере (в `local.json`) и выводятся
  в вашем Excel-файле.
- **Общая база (справочник)**: при добавлении или изменении подписанта
  данные сохраняются и в общий `tabel_data.json` (раздел `shared_signers`) —
  чтобы его видели коллеги.
- **Защита от дубликатов**: программа не позволит добавить одного и того же
  подписанта (с одинаковой должностью и ФИО) в ваш список дважды.
- **Кнопка «Удалить»** (в основном окне): убирает подписанта **только из вашего локального списка печати**. В общей базе он остаётся, и вы можете добавить его обратно в любой момент.
- **Кнопка «Выбрать...»**: открывает общую базу с поиском. Именно в этом окне доступно **полное удаление из базы** (удалится у всех пользователей после синхронизации) или **редактирование** данных подписанта (действия защищены паролем).
- **Снять галочку** — скрыть подписанта только из своего Excel, оставив в базе для коллег.

## Экспорт в Excel

Кнопка «Сохранить в Excel» на вкладке «Отчёт и печать» формирует файл вида:

```
Табель/<Отдел>/<Год>/tabel_<ГГГГ-ММ>_full.xlsx
Табель/<Отдел>/<Год>/tabel_<ГГГГ-ММ>_short.xlsx
```

Файл содержит аккуратно свёрстанную шапку, подсветку выходных,
итоги и подписи.

**Особенности экспорта:**

- В файл выгружаются только те колонки итогов, которые вы отметили
  в окне «Настроить итоги».
- Ширина колонок подстраивается автоматически под самые длинные
  введённые значения (например, под `8//2`).
- Есть две кнопки: **«Сохранить в Excel»** (полный) и **«Кратко в Excel»** (ФИО + дни + Всего + Выходные).
- Галочка **«Условные обозначения»** добавляет в конец файла расшифровку кодов.

Для экспорта требуется библиотека `openpyxl` — она устанавливается
вместе с остальными зависимостями через `requirements.txt`.

## Сворачивание отделов

Клик по полосе отдела (там, где название) **сворачивает/разворачивает** список сотрудников.
Состояние запоминается в `local.json` и не пересекается с коллегами.

Правый клик по полосе отдела открывает меню: «Отдел вверх / вниз /
в начало списка / в конец списка». Правый клик по сотруднику — аналогичное меню.

## Частые вопросы

**«Программа уже запущена» при старте `.exe`**
Это защита от повторного запуска (Mutex). Переключитесь на уже открытое окно.

**«Сотрудник X уже существует» при добавлении**
ФИО (без учёта регистра) проверяется на уникальность. Если сотрудник
с таким ФИО уже есть в другом отделе — программа предупредит.

**«Табель уже ведётся по отделу Y»**
Это ограничение: одновременно ведётся только один отдел. Снимите
галочки «В таблицу» у сотрудников текущего отдела, затем отмечайте другой.

**Не сохраняются ручные правки итогов**
Нажмите «Применить правки» или выйдите из ячейки через `Enter`.
Также подождите ~0,6 с — автосохранение срабатывает с задержкой.

**Не подхватываются изменения с другого ПК**
- Проверьте, что оба компьютера работают с одним и тем же `tabel_data.json`.
- Синхронизация идёт раз в ~3 секунды. Подождите пару секунд.
- Если файл лежит на сетевом диске — убедитесь, что нет проблем с доступом.

**Не открывается Excel — ошибка про openpyxl**
Проверьте, что `openpyxl` установлен и включён в сборку (`hiddenimports` в `main.spec`).

**Почему при удалении подписанта в окне «Доп. подписанты» он не исчезает из общей базы?**
Это сделано специально: кнопка «Удалить» в этом окне убирает человека только из вашего списка печати, чтобы он не попадал в ваш Excel. Если его нужно удалить для всех, нажмите «Выбрать...», найдите его в списке и нажмите «Удалить» там (потребуется пароль).
