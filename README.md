# Табель учёта рабочего времени

Настольное приложение на Python + Kivy для ведения табеля учёта рабочего времени по форме Т-13 (упрощённой). Работает локально, без интернета и без базы данных — все данные хранятся в одном JSON-файле рядом с программой.

## Возможности

- **Справочник сотрудников** — отделы, должности, ФИО. Сотрудники группируются по отделам; поддерживается переименование и удаление.
- **Ведение табеля по месяцам** — ввод часов или буквенных кодов (В, О, Б, А, Р, Н, П, Т, Ц, У) в ячейку дня.
- **Автоматический расчёт итогов** по каждому сотруднику: явки, неявки по категориям, сумма часов, сверхурочные, ночные и праздничные.
- **Три настраиваемых признака должности** — «Ночные», «Сверхурочные», «Праздничные». Применяются ко всем сотрудникам с этой должностью автоматически. По умолчанию все три выключены.
- **Ручная корректировка** любой ячейки итогов с возможностью вернуться к авто-расчёту.
- **Навигация с клавиатуры** — Tab / Shift+Tab / стрелки перемещают фокус между ячейками, как в Excel. Введённое значение автоматически выделяется для быстрой перезаписи.
- **Автосохранение** через 0,6 с после последнего изменения. Внешние правки `tabel_data.json` подхватываются без перезапуска.
- **Экспорт в Excel** (.xlsx) — готовый оформленный табель с шапкой, подсветкой выходных, строкой ИТОГО и подписями.
- **Редактируемые подписи** — ФИО Энергетика и Директора задаются в один клик и сохраняются между запусками.
- **Иконка** окна и панели задач из `ico/tabel.ico` (Windows). Если файла нет — в заголовке появляется текстовый маркер.

## Требования

- **Python** 3.9 или новее
- **ОС**: Windows / Linux / macOS (иконка панели задач ставится через WinAPI — работает только на Windows)
- **Шрифт Arial** (на Windows уже есть; на Linux/macOS автоматически используется Roboto)
- **Зависимости**:
  - `kivy >= 2.2`
  - `openpyxl >= 3.0` (для экспорта в Excel)
  - `pyinstaller >= 6.0` (только для сборки `.exe`)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Londimain/Work-schedule.git
cd Work-schedule
```

### 2. Виртуальное окружение (рекомендуется)

**Windows:**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install kivy openpyxl
```

### 4. Запуск

```bash
python main.py
```

При первом запуске рядом с `main.py` создастся файл `tabel_data.json` — там будут храниться все данные.

## Сборка в .exe

Для создания одного автономного `.exe` (Windows) используется **PyInstaller**.

### 1. Установка

```bash
pip install pyinstaller
```

> Устанавливать нужно **в тот же venv**, из которого потом запускается сборка. Иначе `openpyxl` не попадёт в `.exe` — самая частая причина ошибки «Нужен openpyxl».

### 2. Сборка одной командой

```powershell
pyinstaller --onefile --windowed --icon=ico\tabel.ico --add-data "ico\tabel.ico;ico" --collect-all openpyxl main.py
```

Готовый файл появится в `dist\main.exe`.

**Что делают ключи:**

| Ключ | Назначение |
|---|---|
| `--onefile` | Упаковать всё в один `.exe` |
| `--windowed` | Без окна консоли |
| `--icon=ico\tabel.ico` | Иконка самого `.exe` (видна в проводнике) |
| `--add-data "ico\tabel.ico;ico"` | Встроить иконку внутрь сборки, чтобы её нашёл код для окна и панели задач |
| `--collect-all openpyxl` | Гарантированно включить `openpyxl` и его зависимости в сборку |

### 3. Сборка через `.spec` (рекомендуется для повторных сборок)

Один раз создайте спецификацию:

```powershell
pyi-makespec --onefile --windowed --icon=ico\tabel.ico --add-data "ico\tabel.ico;ico" main.py
```

Откройте `main.spec`, убедитесь, что в `Analysis(...)` есть:

```python
datas=[('ico/tabel.ico', 'ico')],
hiddenimports=['openpyxl', 'et_xmlfile'],
```

Дальше собирайте так:

```powershell
python -m PyInstaller --clean --noconfirm main.spec
```

> Собирайте через `python -m PyInstaller ...`, а не через `pyinstaller ...` — так исключается путаница с несколькими установленными версиями.

### 4. Возможные проблемы

- **«Нужен openpyxl» в собранном `.exe`** — `openpyxl` не попал в сборку. Причины: (1) он не установлен в том venv, из которого собираете; (2) собираете через `pyinstaller.exe` из другого Python, а не через `python -m PyInstaller`. Проверьте `python -c "import openpyxl; print(openpyxl.__version__)"` — команда должна работать в том же окне, где вы запускаете сборку.
- **Иконка `.exe` не обновилась** — сбросьте кэш иконок Windows: `ie4uinit.exe -show` или перезагрузитесь. Папку `build\` удаляйте перед сборкой (`--clean`).
- **Антивирус удаляет `.exe`** — так бывает с любыми PyInstaller-сборками без цифровой подписи. Добавьте `dist\` в исключения.
- **Размер `.exe` 60–100 МБ** — нормально для Kivy + openpyxl.

### 5. Где `.exe` хранит данные

Файл `tabel_data.json` создаётся **рядом с `.exe`** (в той же папке). Не кладите `.exe` в `C:\Program Files\` — там Windows запретит запись. Используйте пользовательскую папку, например `D:\Tabel\`.

## Как пользоваться

### Вкладка «Рабочий персонал»

1. **«+ Должность»** — список должностей. Для каждой задаются три признака:
   - **Ночные** — считать ночные часы по шкале 4→1, 5→2, 6→3, 7–11→6.
   - **Сверхурочные** — считать всё, что превышает норму месяца (число рабочих дней × 8).
   - **Праздничные** — часы в выходные и праздники идут в отдельную колонку. Если снять галочку, эти часы считаются как обычные явки и часы, а при включённых «Ночных» учитываются ещё и ночные.
2. **«+ Отдел»** — список отделов.
3. **«+ Добавить сотрудника»** — карточка с ФИО, отделом и должностью.
4. Галочка **«В таблицу»** — определяет, попадает ли сотрудник в табель. У **нового** сотрудника галочка по умолчанию снята.
5. Одновременно активен только один отдел. При попытке включить сотрудника из другого отдела программа предупредит.

### Вкладка «Табель»

Основная рабочая область. Сверху выбирается месяц и год. Таблица состоит из трёх панелей, которые прокручиваются синхронно:

- **Слева** — №, ФИО, должность (шапка фиксирована).
- **В центре** — дни месяца. В ячейку вводится либо число часов (`8` или `7.5`), либо код:

  | Код | Значение |
  |---|---|
  | В | выходной |
  | О | трудовой отпуск |
  | Б | больничный |
  | А | отпуск за свой счёт |
  | Р | отпуск по родам |
  | Н | прочие неявки |
  | П | прогул |
  | Т | текущий простой |
  | Ц | целосменный простой |
  | У | опоздание |

- **Справа** — итоги, пересчитываются сразу при вводе.

**Кнопки сверху:**

| Кнопка | Действие |
|---|---|
| Сбросить правки | Вернуть все ручные правки итогов за месяц к авто-расчёту |
| Применить правки | Зафиксировать текущие ручные значения |
| Очистить | Удалить все данные табеля за выбранный месяц (с подтверждением) |

**Ручные правки.** Любую ячейку в правой панели можно отредактировать вручную — она перестанет пересчитываться автоматически. Если очистить её — авто-расчёт вернётся.

**Автосохранение** происходит через 0,6 с после последнего изменения. Дополнительно нажимать «Сохранить» не нужно.

### Вкладка «Отчёт и печать»

Сводка за месяц по всем сотрудникам, отмеченным «В таблицу»: явки, неявки по категориям, часы, сверхурочные, ночные, праздничные, а также построчная разбивка по каждому сотруднику.

**Кнопка «Подписи»** — задаёт ФИО Энергетика и Директора. Они автоматически подставляются в подписи готового Excel-файла и сохраняются между запусками.

**Кнопка «Сохранить в Excel»** формирует файл `tabel_ГОД-МЕСЯЦ.xlsx`:

- заголовок и шапка с числами месяца и днями недели;
- подсветка выходных и праздников;
- строки сотрудников и строка ИТОГО;
- подписи «Энергетик» и «Директор».

Файл сразу открывается в Excel. Требуется библиотека `openpyxl`.

## Горячие клавиши

Кликните в ячейку и работайте без мыши:

| Клавиша | Действие |
|---|---|
| **Tab** | Следующая ячейка: следующее число → затем итоги → затем первый день следующего сотрудника |
| **Shift+Tab** | Предыдущая ячейка (в обратном порядке) |
| **← / →** | Курсор внутри ячейки; если упёрся в край — переход к соседней |
| **↓ / ↑** | Тот же столбец, соседний сотрудник |

При переходе текст в новой ячейке **автоматически выделяется** — можно сразу набирать новое значение. Горизонтальная прокрутка подтягивает активную ячейку в видимую область; вертикальное положение таблицы не меняется.

## Формат данных

Все данные хранятся в одном файле **`tabel_data.json`** рядом с программой (или с `.exe`). Структура:

```json
{
  "employees": [
    {
      "id": "emp_1791232249029",
      "name": "Ильенков С.М.",
      "position": "электромонтер",
      "department": "ЭНЕРГОСЛУЖБА",
      "show_in_timesheet": true
    }
  ],
  "timesheets": {
    "2026-10": {
      "emp_1791232249029": {
        "1": "8",
        "3": "В",
        "5": "7.5"
      }
    }
  },
  "positions": ["электромонтер", "оператор котельной"],
  "departments": ["ЭНЕРГОСЛУЖБА"],
  "organization": "ОАО \"Компания \"МогНат\"",
  "night_flags": {"оператор котельной": true},
  "overtime_flags": {"электромонтер": true},
  "holiday_flags": {"электромонтер": true},
  "result_overrides": {
    "2026-10": {
      "emp_1791491050354": {"праздничные": "20"}
    }
  },
  "energetic_name": "Борщенков С.В.",
  "director_name": "Авчинников С. А."
}
```

| Ключ | Описание |
|---|---|
| `employees` | Список сотрудников. `id` — уникальный идентификатор. |
| `timesheets` | Значения ячеек по месяцам в формате `год-месяц` → `id_сотрудника` → `день месяца` → `значение`. |
| `positions`, `departments` | Справочники должностей и отделов. |
| `organization` | Название организации (попадает в отчёт и Excel). |
| `night_flags`, `overtime_flags`, `holiday_flags` | Признаки должностей. |
| `result_overrides` | Ручные правки итогов по месяцам. |
| `energetic_name`, `director_name` | ФИО для подписей в Excel. |

> Файл можно редактировать вручную в любом текстовом редакторе. Программа подхватит изменения в течение 3 секунд без перезапуска.

## Резервное копирование

Просто скопируйте файл `tabel_data.json` в надёжное место. Этого достаточно — вся информация о сотрудниках, справочниках и табелях хранится именно там.

Если программа собрана в `.exe`, файл данных создаётся в той же папке, где лежит `.exe`.

## Известные ограничения

- **Один отдел одновременно.** Нельзя вести табели для двух отделов в один период.
- **Ручные правки итогов хранятся отдельно по месяцам.** При переключении периода отображаются правки именно этого периода.
- **Иконка на панели задач** ставится через WinAPI и работает только на Windows.
- **Ночные часы** считаются по фиксированной шкале (4→1, 5→2, 6→3, 7–11→6). Если нужна другая формула — правьте `calc_night_hours` в `data_utils.py`.
- **Праздники захардкожены** в `config.py` (множество `HOLIDAYS`). Список можно дополнить вручную.
- **Шрифт Arial.** На Windows берётся из `C:\Windows\Fonts\arial.ttf`. На других ОС автоматически используется Roboto — визуально интерфейс немного отличается, но полностью работоспособен.
- **Кириллица в `.exe`** отображается корректно при наличии Arial в системе.
