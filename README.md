# Табель учёта рабочего времени

Настольное приложение на Python + Kivy для ведения табеля учёта рабочего времени по форме Т-13 (упрощённой). Работает локально, без интернета и без базы данных — все общие данные хранятся в одном JSON-файле рядом с программой, а персональные настройки каждого компьютера — в отдельном локальном файле.

## Возможности

- **Справочник сотрудников** — отделы, должности, ФИО. Сотрудники группируются по отделам; поддерживается переименование и удаление.
- **Отметка «На контракте»** — позволяет отделить сотрудников, входящих в списочную численность.
- **Ведение табеля по месяцам** — ввод часов, часов со сменой или буквенных кодов (В, О, Б, А, Р, Н, П, Т, Ц, У) в ячейку дня.
- **Формат `ЧАСЫ//СМЕНА`** — если работа сменная, в ячейку можно ввести `8//1` (8 часов, первая смена) или `8//2` (8 часов, вторая смена). Ночные считаются по шкале смен.
- **Автоматический расчёт итогов** по каждому сотруднику: явки, неявки по категориям, сумма часов, сверхурочные, ночные и праздничные. *(Часы, отработанные в выходные/праздники, исключаются из расчёта сверхурочных).*
- **Два настраиваемых признака должности** — «Ночные» и «Сверхурочные». Применяются ко всем сотрудникам с этой должностью автоматически. По умолчанию оба выключены.
- **Списочная и среднесписочная численность** — автоматический расчёт в отчёте и выгрузке в Excel.
- **Ручная корректировка** любой ячейки итогов с возможностью вернуться к авто-расчёту.
- **Навигация с клавиатуры** — Tab / Shift+Tab / стрелки перемещают фокус между ячейками, как в Excel.
- **Копирование и вставка** — Ctrl+C / Ctrl+V работают как в Excel.
- **Выделение диапазона** — Shift+клик, клавиша Del очищает выделение.
- **Индивидуальный выбор сотрудников в табеле** — галочка «В таблицу» хранится локально.
- **Свободная перестановка** сотрудников и отделов через правое контекстное меню.
- **Индивидуальные подписи отделов** — у каждого отдела свой руководитель (пара «должность + ФИО»).
- **Директор** — общее ФИО организации, редактируется в верхней панели.
- **Защита удаления паролем** — пароль по умолчанию `admins`.
- **Автосохранение** через 0,6 с. Внешние правки подхватываются без перезапуска.
- **Экспорт в Excel** (.xlsx) — готовый оформленный табель с шапкой, подсветкой выходных, ИТОГО, численностью и двумя подписями.
- **Сборка в один .exe** через `main.spec`.

## Требования

- **Python** 3.9 или новее
- **ОС**: Windows / Linux / macOS (иконка панели задач ставится через WinAPI — работает только на Windows)
- **Шрифт Arial** (на Windows уже есть; на Linux/macOS автоматически используется Roboto)
- **Зависимости**:
  - `kivy >= 2.2`
  - `openpyxl >= 3.0` (для экспорта в Excel)
  - `pyinstaller >= 6.0` (только для сборки `.exe`)

Установка зависимостей:

```bash
pip install kivy openpyxl pyinstaller
```

## Сборка в .exe

В репозитории уже есть готовый `main.spec` — PyInstaller-конфиг с иконкой, шрифтом и собранным openpyxl. Пересобирать `.spec` не нужно.

### Команды для сборки (PowerShell)

```powershell
Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force __pycache__ -ErrorAction SilentlyContinue
python -m PyInstaller --clean --noconfirm main.spec
```

### Результат

- `dist/main/main.exe` — исполняемый файл
- `dist/main/_internal/` — служебные файлы (DLL Kivy, шрифты, `ico/tabel.ico`, openpyxl)

Переносите на другой компьютер **всю папку** `dist/main`.

## Как пользоваться

### Вкладка «Рабочий персонал»

1. **Добавьте отделы** кнопкой «+ Отдел». У каждого отдела обязательно должны быть Название, Должность руководителя и ФИО руководителя.

2. **Добавьте должности сотрудников** кнопкой «+ Должность» (например «электромонтер»). Для каждой должности задаются два признака:
   - **Ночные** — считаются ночные часы. Способ расчёта зависит от формата ячейки дня:
     - **часы со сменой** (`8//1`, `8//2`, `10//2` и т.п.) — по шкале смен (см. ниже);
     - **простое число** (`8`, `7.5` и т.п.) — по старой шкале: 4 ч → 1, 5 ч → 2, 6 ч → 3, 7–11 ч → 6.
   - **Сверхурочные** — считаются часы сверх нормы (число рабочих дней × 8). Часы, отработанные в выходные и праздничные дни, из расчёта исключаются.

3. **Добавьте сотрудников** кнопкой «+ Добавить сотрудника»: ФИО, отдел, должность. В карточке сотрудника есть две галочки:
   - **На контракте** — учитывается при расчёте списочной численности.
   - **В таблицу** — определяет, попадёт ли сотрудник в табель **на этом компьютере**.

> **Важно про галочку «В таблицу».** Выбор галочек **хранится локально** на каждом компьютере (`local.json`) и **не синхронизируется**. Одновременно табель на конкретном компьютере может вестись **только по одному отделу**.

### Вкладка «Табель»

1. Выберите **месяц** и **год** вверху.
2. В ячейки дней вводите **число часов**, **часы со сменой** (`8//2`) или **буквенный код** (В, О, Б, А, Р, Н, П, Т, Ц, У).
3. **Особенности расчёта выходных:** если вы вводите часы (например, 8) в субботу или праздник, они автоматически:
   - идут в колонку «праздничные»;
   - добавляются к «Всего» часов;
   - добавляют +1 к «Факт. работы» (явки);
   - **исключаются из расчёта сверхурочных**, чтобы избежать двойной оплаты.
4. Итоги справа пересчитываются автоматически. Их можно корректировать вручную.

### Вкладка «Отчёт и печать»

1. Выберите месяц и год.
2. Кнопка **«Сохранить в Excel»** формирует файл `tabel_ГОД-МЕСЯЦ.xlsx` и открывает его.
3. В файле помимо таблицы и подписей выводятся **Списочная** и **Среднесписочная** численность.

## Формат ввода в ячейку дня

В ячейку дня можно ввести одно из трёх:

### 1. Буквенный код неявки

| Код | Что означает | Куда попадает |
|---|---|---|
| `В` | Выходной | «Выходной» |
| `О` | Трудовой отпуск | «Трудовой отпуск» |
| `Б` | Больничный | «Болезнь» |
| `А` | Отпуск за свой счёт | «Отпуск без з/п» |
| `Р` | Отпуск по родам | «Отп. по родам» |
| `Н` | Прочие неявки | «Проч. неявки» |
| `П` | Прогул | «Прогул» |
| `Т` | Текущий простой | «Текущий простой» |
| `Ц` | Целосменный простой | «Целосмен. простой» |
| `У` | Опоздание | «Опоздания» |

### 2. Простое число часов

`8`, `7.5`, `4` и т.п. Влияет на:
- «Факт. работы» (явки) → +1 за каждый непустой день;
- «Всего» часов → + все введённые часы;
- «праздничные» → + все часы, если день выходной/праздничный;
- «ночные» → по старой шкале (только если у должности включён признак «Ночные»):
  - 4 ч → 1 ночной
  - 5 ч → 2
  - 6 ч → 3
  - 7–11 ч → 6

### 3. Часы со сменой — `ЧАСЫ//СМЕНА`

Формат: два числа, разделённые **двумя слэшами** `/`.

| Ввод | Смена | Ночные | Пояснение |
|---|---|---|---|
| `8//1` | Первая | **0** | Первая смена ночных не даёт никогда |
| `8//2` | Вторая | **1** | 8 ч → 1 ночной |
| `9//2` | Вторая | **2** | 9 ч → 2 ночных |
| `10//2` | Вторая | **3** | 10 ч → 3 ночных |
| `11//2` | Вторая | **4** | 11 ч → 4 ночных |
| `12//2` | Вторая | **4** | 12 ч → 4 ночных |
| `13//2` | Вторая | **5** | 13 ч → 5 ночных |
| `14//2` | Вторая | **6** | 14 ч → 6 ночных |
| `15//2` | Вторая | **7** | 15 ч → 7 ночных |

**Что происходит при вводе `8//2`:**
- «Факт. работы» (явки) → +1;
- «Всего» часов → +8;
- «ночные» → +1;
- если день выходной или праздничный → эти же 8 часов дополнительно попадут в «праздничные».

**Важно:**
- Номер смены влияет **только** на расчёт ночных. На явки, «Всего» и «праздничные» он не влияет.
- Смена не привязана к дню месяца: `8//2` 1-го числа даст 1 ночной, и 15-го числа тоже.
- Если ввести `8//2`, но у должности **не стоит** галочка «Ночные» — ночные не считаются.
- Два слэша должны быть **обычными** `/` (ASCII, U+002F). «Похожие» символы `∕`, `／`, `⁄` не распознаются.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Tab` / `Shift+Tab` | Переход к следующей / предыдущей ячейке |
| `←` / `→` | Курсор внутри ячейки; на краю — переход к соседней |
| `↑` / `↓` | Тот же столбец, соседняя строка |
| `Ctrl+C` / `Ctrl+V` | Копировать / вставить значение или диапазон |
| `Del` | Очистить активную ячейку или всё выделение |
| `Shift + клик` | Выделить прямоугольный диапазон ячеек |

## Формат данных

### Общий файл `tabel_data.json`

```json
{
  "employees": [
    {
      "id": "emp_...",
      "name": "Ильенков С.М.",
      "position": "электромонтер",
      "department": "ЭНЕРГОСЛУЖБА",
      "is_contract": true
    }
  ],
  "timesheets": {
    "2026-10": {
      "emp_...": { "6": "4", "19": "2", "23": "8//2" }
    }
  },
  "positions": ["электромонтер", "оператор котельной"],
  "night_flags":    { "электромонтер": false, "оператор котельной": true },
  "overtime_flags": { "электромонтер": true,  "оператор котельной": false },
  "departments": ["ЭНЕРГОСЛУЖБА"],
  "signer_positions": ["Энергетик", "Начальник цеха"],
  "department_signer": {
    "ЭНЕРГОСЛУЖБА": {
      "position": "Энергетик",
      "name": "Борщенков С.В."
    }
  },
  "organization": "ОАО \"Компания \"МогНат\"",
  "director_name": "С. А. Авчинников",
  "result_overrides": { "2026-10": {} }
}
```

Обратите внимание: в `timesheets` значения — строки. `"8//2"` хранится как есть, расчёт ночных выполняется на лету.

### Локальный файл `local.json`

Создаётся в `%APPDATA%\TabelApp\local.json` (Windows) или `~/.config/TabelApp/local.json` (Linux/macOS). Содержит:
- `show_in_timesheet` — какие сотрудники отображаются в табеле на этой машине;
- `departments_order` и `employees_order` — локальный порядок отделов и сотрудников.

## Совместная работа на нескольких компьютерах

Общий файл `tabel_data.json` может лежать на сетевом диске. Галочки «В таблицу» и порядок строк при этом остаются локальными для каждой машины. Это позволяет на одной машине вести табель по одному отделу, а на другой — по другому.

## Резервное копирование

**Основные данные** — скопируйте файл `tabel_data.json`.

**Локальные настройки** — файл `local.json` (обычно не требует резервирования).

## Известные ограничения

- Одновременно табель на **конкретном компьютере** ведётся **только по одному отделу**.
- Иконка панели задач через WinAPI — **только Windows**.
- Для экспорта в Excel нужен `openpyxl`.
- Признак «Ночные» у должности должен быть включён — иначе сменный формат `8//2` не даст ночных.
- Два слэша в `8//2` должны быть обычными ASCII (`/`).
