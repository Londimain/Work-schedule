# Табель учёта рабочего времени

Настольное приложение на Python + Kivy для ведения табеля учёта рабочего времени по форме Т-13 (упрощённой). Работает локально, без интернета и без базы данных — все данные хранятся в одном JSON-файле рядом с программой.

## Возможности

- **Справочник сотрудников** — отделы, должности, ФИО. Сотрудники группируются по отделам, поддерживается переименование и удаление.
- **Ведение табеля по месяцам** — ввод часов или буквенных кодов (В, О, Б, А, Р, Н, П, Т, Ц, У) в ячейку дня.
- **Автоматический расчёт итогов** по каждому сотруднику:
  - явки, неявки по категориям;
  - сумма отработанных часов;
  - сверхурочные (сравнение с нормой месяца);
  - ночные часы по специальной шкале;
  - праздничные часы.
- **Три настраиваемых признака должности**: «Ночные», «Сверхурочные», «Праздничные». Назначаются автоматически всем сотрудникам с этой должностью.
- **Ручная корректировка** любой ячейки итогов с возможностью вернуться к авто-расчёту.
- **Автосохранение** через 0,6 с после последнего изменения. Внешние правки `tabel_data.json` подхватываются без перезапуска.
- **Экспорт в Excel** (.xlsx) — готовый оформленный табель с шапкой, подсветкой выходных, строкой ИТОГО и подписями.
- **Иконка** окна и панели задач из `ico/tabel.ico` (Windows). Если файла нет — в заголовке автоматически появляется эмодзи 📋.

## Требования

- **Python** 3.9 или новее
- **ОС**: Windows / Linux / macOS (иконка панели задач — Windows; на других ОС работает через SDL)
- **Шрифт Arial** (на Windows уже есть; на Linux/macOS автоматически используется Roboto)
- **Зависимости**:
  - `kivy >= 2.2`
  - `openpyxl >= 3.0` (для экспорта в Excel)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/<ваш-логин>/tabel-app.git
cd tabel-app
```

### 2. Виртуальное окружение (рекомендуется)

**Windows:**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install kivy openpyxl
```

### 4. Запуск

```bash
python main.py
```

При первом запуске рядом с `main.py` создастся файл `tabel_data.json` — там будут храниться все данные.

## Сборка в .exe

Для создания одного автономного `.exe` (Windows) используется **PyInstaller**.

### 1. Установка

```bash
pip install pyinstaller
```

### 2. Сборка (одной командой)

```powershell
pyinstaller --onefile --windowed --icon=ico\tabel.ico --add-data "ico\tabel.ico;ico" main.py
```

Готовый файл появится в `dist\main.exe`.

**Что делают ключи:**

| Ключ | Назначение |
|---|---|
| `--onefile` | Упаковать всё в один `.exe` |
| `--windowed` | Без окна консоли |
| `--icon=ico\tabel.ico` | Иконка самого `.exe` (видна в проводнике) |
| `--add-data "ico\tabel.ico;ico"` | Встроить иконку внутрь сборки, чтобы её нашёл код для окна и панели задач |

### 3. Сборка через `.spec`-файл (для повторных сборок)

Один раз создайте спецификацию:

```powershell
pyi-makespec --onefile --windowed --icon=ico\tabel.ico --add-data "ico\tabel.ico;ico" main.py
```

Дальше собирайте так:

```powershell
pyinstaller --clean --noconfirm main.spec
```

### 4. Возможные проблемы

- **Иконка `.exe` не обновилась** — сбросьте кэш иконок Windows: `ie4uinit.exe -show` или перезагрузитесь. Папку `build\` лучше удалять перед новой сборкой (`--clean`).
- **Антивирус удаляет `.exe`** — так бывает с любыми PyInstaller-сборками без цифровой подписи. Добавьте `dist\` в исключения.
- **Размер `.exe` 40–80 МБ** — это нормально для Kivy. Уменьшать вручную нужно с осторожностью, исключая модули через `excludes` в `.spec`.

## Структура проекта

```
tabel-app/
├── main.py              # Точка входа, верхняя панель, вкладки
├── config.py            # Настройка Kivy, шрифт, константы, иконка
├── data_utils.py        # Загрузка/сохранение данных, пересчёт итогов
├── ui_helpers.py        # Границы, измерения, синхронная прокрутка
├── ui_widgets.py        # Кастомные виджеты (поля, спиннеры, ячейки)
├── tab_employees.py     # Вкладка «Рабочий персонал»
├── tab_timesheet.py     # Вкладка «Табель»
├── tab_report.py        # Вкладка «Отчёт и печать» (в т.ч. Excel)
├── tab_about.py         # Вкладка «О программе»
├── tabel_data.json      # Все данные (создаётся автоматически)
└── ico/
    └── tabel.ico        # Иконка окна и панели задач (опционально)
```

### Модули: назначение

| Файл | Ответственность |
|---|---|
| `config.py` | Единая точка настройки. **Импортируется первым** — выставляет параметры Kivy до создания окон. Регистрирует шрифт, содержит константы (цвета, размеры, коды, шаблоны) и функции работы с иконкой. |
| `data_utils.py` | Чтение/запись `tabel_data.json`, классификация дней (рабочий/выходной/праздник), расчёт итогов по строке. |
| `ui_helpers.py` | Вспомогательные функции: рамки, измерение текста, синхронная прокрутка трёх панелей, горизонтальный скролл колесом. |
| `ui_widgets.py` | Кастомные виджеты: `CenteredField`, `CenteredSpinner`, `VerticalLabel`, `DayCell`, `ResultCell`, `DayHeader`. |
| `tab_*.py` | Каждая вкладка — отдельный виджет-класс. Собираются в `main.py`. |

## Как пользоваться

### Вкладка «Рабочий персонал»

Это справочник. Здесь ведут отделы и должности, добавляют и редактируют сотрудников.

1. Кнопка **«+ Должность»** — список должностей. Для каждой задаются три признака:
   - **Ночные** — считать ночные часы по шкале 4→1, 5→2, 6→3, 7–11→6.
   - **Сверхурочные** — считать всё, что превышает норму месяца.
   - **Праздничные** — часы в выходные и праздники идут в отдельную колонку. Если снять галочку, часы считаются как обычные явки.
2. Кнопка **«+ Отдел»** — список отделов.
3. Кнопка **«+ Добавить сотрудника»** — карточка с ФИО, отделом и должностью.
4. Галочка **«В таблицу»** — определяет, попадает ли сотрудник в табель. Одновременно активен только один отдел: при попытке включить сотрудника из другого отдела программа предупредит.

### Вкладка «Табель»

Основная рабочая область. Сверху выбирается месяц и год. Таблица состоит из трёх панелей, которые прокручиваются синхронно:

- **Слева** — №, ФИО, должность (шапка фиксирована).
- **В центре** — дни месяца. В ячейку вводится либо число часов (например, `8` или `7.5`), либо код:

  | Код | Значение |
  |---|---|
  | В | выходной |
  | О | трудовой отпуск |
  | Б | больничный |
  | А | отпуск за свой счёт |
  | Р | отпуск по родам |
  | Н | прочие неявки |
  | П | прогул |
  | Т | текущий простой |
  | Ц | целосменный простой |
  | У | опоздание |

- **Справа** — итоги, пересчитываются сразу при вводе.

**Кнопки сверху:**

| Кнопка | Действие |
|---|---|
| Сбросить правки | Вернуть все ручные правки итогов за месяц к авто-расчёту |
| Применить правки | Зафиксировать текущие ручные значения |
| Очистить | Удалить все данные табеля за выбранный месяц (с подтверждением) |

**Ручные правки.** Любую ячейку в правой панели можно отредактировать вручную — она перестанет пересчитываться автоматически. Если очистить её — авто-расчёт вернётся.

**Автосохранение** происходит через 0,6 с после последнего изменения. Дополнительно нажимать «Сохранить» не нужно.

### Вкладка «Отчёт и печать»

Сводка за месяц по всем сотрудникам, отмеченным «В таблицу»: явки, неявки по категориям, часы, сверхурочные, ночные, праздничные, а также построчная разбивка по каждому сотруднику.

Кнопка **«Сохранить в Excel»** формирует файл `tabel_ГОД-МЕСЯЦ.xlsx`:

- заголовок и шапка с числами месяца и днями недели;
- подсветка выходных и праздников;
- строки сотрудников и строка ИТОГО;
- подписи «Энергетик» и «Директор».

Файл сразу открывается в Excel. Требуется библиотека `openpyxl`.

## Формат данных

Все данные хранятся в одном файле **`tabel_data.json`** рядом с программой. Структура:

```json
{
  "employees": [
    {
      "id": "emp_1791232249029",
      "name": "Ильенков С.М.",
      "position": "электромонтер",
      "department": "ЭНЕРГОСЛУЖБА",
      "show_in_timesheet": true
    }
  ],
  "timesheets": {
    "2026-10": {
      "emp_1791232249029": {
        "1": "8",
        "3": "В",
        "5": "7.5"
      }
    }
  },
  "positions": ["электромонтер", "оператор котельной"],
  "departments": ["ЭНЕРГОСЛУЖБА"],
  "organization": "ОАО \"Компания \"МогНат\"",
  "night_flags": {"оператор котельной": true},
  "overtime_flags": {"электромонтер": true},
  "holiday_flags": {"электромонтер": true},
  "result_overrides": {
    "2026-10": {
      "emp_1791491050354": {"праздничные": "20"}
    }
  }
}
```

| Ключ | Описание |
|---|---|
| `employees` | Список сотрудников. `id` — уникальный идентификатор. |
| `timesheets` | Значения ячеек по месяцам в формате `год-месяц` → `id_сотрудника` → `день месяца` → `значение`. |
| `positions`, `departments` | Справочники должностей и отделов. |
| `organization` | Название организации (попадает в отчёт и Excel). |
| `night_flags`, `overtime_flags`, `holiday_flags` | Признаки должностей. |
| `result_overrides` | Ручные правки итогов. |

> Файл можно редактировать вручную в любом текстовом редакторе. Программа подхватит изменения в течение 3 секунд без перезапуска.

## Резервное копирование

Просто скопируйте файл `tabel_data.json` в надёжное место. Этого достаточно — вся информация о сотрудниках, справочниках и табелях хранится именно там.

Если программа собрана в `.exe`, файл данных создаётся в той же папке, где лежит `.exe`.

## Известные ограничения

- **Один отдел одновременно.** Нельзя вести табели для двух отделов в один период. Логика построена на том, что табель сдаётся по отделу.
- **Ручная корректировка итогов не сбрасывается при смене месяца.** Правки хранятся отдельно для каждого периода.
- **Иконка на панели задач** ставится через WinAPI и может не отобразиться, если у `.exe` нет прав на `LoadImageW` (редкий случай на Windows с высоким UAC). Приложение при этом работает нормально.
- **Ночные часы** считаются по фиксированной шкале (4→1, 5→2, 6→3, 7–11→6). Если нужна другая формула — правьте `calc_night_hours` в `data_utils.py`.
- **Шрифт Arial.** На Windows берётся из `C:\Windows\Fonts\arial.ttf`. На других ОС автоматически используется Roboto — визуально интерфейс будет выглядеть немного иначе, но полностью работоспособен.
- **Праздники захардкожены** в `config.py` (HOLIDAYS). Список можно дополнить вручную.
