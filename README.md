## Возможности

- **Ежедневный учёт** явок, неявок и отработанных часов.
- **Автоматический расчёт** итогов по каждому сотруднику за месяц:
  явки, неявки по категориям, сумма часов, сверхурочные, ночные
  и праздничные.
- **Списочная и среднесписочная численность** — считается сама.
- **Признаки должностей** «Ночные», «Сверхурочные» и «Без вых.» —
  включают соответствующий расчёт для всех сотрудников этой должности.
- **Гибкий ввод часов**: обычные числа (`8`, `7,5`), смены (`8//2`, `12//2`), пометка «д» (`8д` — без ночных).
- **Коды неявок**: `В`, `О`, `Б`, `А`, `Р`, `Н`, `ДМ`, `П`, `Т`, `Ц`, `У`.
- **Ручная корректировка итогов** с возможностью сброса к авто-расчёту.
- **Скрытие/отображение итогов**: кнопка «Скрыть итоги» позволяет развернуть таблицу на весь экран. Состояние запоминается для каждого ПК.
- **Визуальное выделение**: отдел, в котором хотя бы у одного сотрудника стоит галочка «В таблицу», подсвечивается ярким оранжевым цветом.
- **Навигация как в Excel**: `Tab` / `Shift+Tab`, стрелки, `Ctrl+C` / `Ctrl+V`,
  `Shift+клик` для выделения диапазона, `Del` для очистки.
- **Перестановка** сотрудников внутри отдела и целых отделов — через контекстное меню (правый клик).
- **Сворачивание отделов**: клик по полосе отдела скрывает/показывает сотрудников. Состояние запоминается.
- **Автосохранение** через 0,6 с после последнего изменения.
- **Смена темы оформления** (5 встроенных цветовых схем). Выбранная тема подсвечивается оранжевым.
- **Экспорт в Excel** (`.xlsx`) с готовым оформлением: умная шапка с автоматическим объединением ячеек (текст не наезжает и не обрезается), подсветка выходных/праздников, строка ИТОГО, подписи.
- **Совместная работа**: несколько компьютеров могут работать с общим файлом `tabel_data.json`, при этом у каждого — свои локальные настройки.
- **Защита удаления** и изменения признаков должностей паролем.

## Сборка в .exe (Windows)

Сборка Kivy-приложений имеет свои особенности. Вам потребуется специальный конфигурационный файл `main.spec`, так как обычная команда `pyinstaller main.py` не включит в себя библиотеки Kivy, SDL2 и ANGLE, из-за чего программа вылетит с ошибкой.

### Шаг 1. Установка библиотек для сборки
В активированном виртуальном окружении выполните:
```cmd
pip install pywin32==225
pip install pyinstaller==4.10
pip install kivy.deps.sdl2 kivy.deps.angle
```
*(Примечание: PyInstaller 4.10 выбран как самая стабильная версия для Windows 7. На Windows 10/11 можно использовать и более новые версии).*

### Шаг 2. Создание файла `main.spec`
Создайте в корневой папке проекта файл `main.spec` со следующим содержимым:

```python
# -*- mode: python ; coding: utf-8 -*-
import os
import glob
from kivy import kivy_data_dir
from PyInstaller.utils.hooks import collect_submodules
from kivy_deps import sdl2, angle

# 1. Собираем DLL-файлы Kivy (SDL2 и ANGLE) как кортежи
kivy_bins = []
for p in (sdl2.dep_bins + angle.dep_bins):
    if os.path.isdir(p):
        for f in glob.glob(os.path.join(p, '*')):
            kivy_bins.append((f, '.'))

# 2. Данные Kivy и иконки
datas = [(kivy_data_dir, 'kivy/data')]
datas += [('ico', 'ico')]

# 3. Скрытые импорты
hiddenimports = collect_submodules('kivy', filter=lambda name: not name.startswith('kivy.garden'))
hiddenimports += [
    'openpyxl',
    'openpyxl.styles',
    'openpyxl.utils',
]

block_cipher = None

a = Analysis(
    ['main.py'],
    pathex=[],
    binaries=kivy_bins,
    datas=datas,
    hiddenimports=hiddenimports,
    hookspath=[],
    hooksconfig={},
    runtime_hooks=[],
    excludes=['numpy', 'pandas', 'matplotlib', 'scipy', 'tkinter', 'PIL', 'wx', 'gi', 'gst'],
    win_no_prefer_redirects=False,
    win_private_assemblies=False,
    cipher=block_cipher,
    noarchive=False,
)
pyz = PYZ(a.pure, a.zipped_data, cipher=block_cipher)

exe = EXE(
    pyz,
    a.scripts,
    a.binaries,
    a.zipfiles,
    a.datas,
    [],
    name='Work schedule',
    debug=False,
    bootloader_ignore_signals=False,
    strip=False,
    upx=False,
    upx_exclude=[],
    runtime_tmpdir=None,
    console=False, # Скрывает черное окно консоли
    disable_windowed_traceback=False,
    argv_emulation=False,
    target_arch=None,
    codesign_identity=None,
    entitlements_file=None,
    icon='ico/tabel.ico'
)
```

### Шаг 3. Запуск сборки
Перед сборкой задайте переменные окружения, чтобы Kivy использовал DirectX (ANGLE). Это критически важно для работы на Windows 7 и в VirtualBox.

В командной строке (cmd) выполните:
```cmd
set KIVY_GL_BACKEND=angle_sdl2
python -m PyInstaller --clean --noconfirm main.spec
```

Готовый файл `Work schedule.exe` появится в папке `dist`.

## ⚠️ Особенности запуска на Windows 7

Если вы запускаете программу на Windows 7 (особенно в VirtualBox), стандартный OpenGL может не поддерживаться. В файле `main.py` уже прописаны нужные настройки:

```python
os.environ['KIVY_GL_BACKEND'] = 'angle_sdl2'
os.environ['ANGLE_DEFAULT_PLATFORM'] = 'd3d9'
```
Если программа при запуске выдает ошибку `GL: Minimum required OpenGL version (2.0) NOT found!`, убедитесь, что вы:
1. Задали `set KIVY_GL_BACKEND=angle_sdl2` перед сборкой.
2. Установили пакет `kivy.deps.angle`.
3. В `main.spec` в `binaries` передаются DLL из папки `angle`.

## Форматы ввода в табеле

### Коды неявок

| Код  |              Расшифровка               |    Колонка итогов    |
|------|----------------------------------------|----------------------|
| `В`  | выходной                               | Выходной             |
| `О`  | трудовой отпуск                        | Трудовой отпуск      |
| `Б`  | больничный                             | Болезнь              |
| `А`  | отпуск за свой счёт                    | Отпуск без з/п       |
| `Р`  | отпуск по родам                        | Отп. по родам        |
| `Н`  | прочие неявки                          | Прочие неявки        |
| `ДМ` | прочие неявки, день матери             | Прочие неявки        |
| `П`  | прогул                                 | Прогул               |
| `Т`  | текущий простой                        | Текущий простой      |
| `Ц`  | целосменный простой                    | Целосмен. простой    |
| `У`  | опоздание                              | Опоздания            |

Регистр не важен: `дм`, `Дм`, `ДМ` — одно и то же.

### Часы и смены

| Ввод      | Явки | Всего | Ночные | Праздничные        |
|-----------|------|-------|--------|--------------------|
| `8`       | +1   | +8    | **0**  | +8 в вых./праздн. |
| `7,5`     | +1   | +7,5  | по шкале | +7,5 в вых./праздн. |
| `8//1`    | +1   | +8    | **0**  | +8 в вых./праздн. |
| `8//2`    | +1   | +8    | +1     | +8 в вых./праздн. |
| `12//2`   | +1   | +12   | +8     | +12 в вых./праздн. |
| `8д`      | +1   | +8    | **0**  | +8 в вых./праздн. |

**Шкала ночных для второй смены:**
```
 8 → 1     9 → 2    10 → 3    11 → 4
12 → 8    13 → 8    14 → 8    15 → 8
```
Для первой смены (`//1`) ночных всегда **0**, независимо от часов.

**Без указания смены** ночные считаются по старой шкале:
`4 → 1, 5 → 2, 6 → 3, 7–11 → 6`, иначе `0`. Обычная цифра `8` ночных не дает (как и `8д`).

### Сверхурочные

Считаются только по часам, отработанным в рабочие дни:
```
сверхурочные = (всего_часов − праздничные) − норма
норма = рабочих_дней_в_месяце × 8
```
Часы, отработанные в выходные и праздники, идут в «праздничные»
и **не** участвуют в расчёте сверхурочных (защита от двойной оплаты).

## Навигация и Горячие клавиши

| Клавиши            | Действие                                        |
|--------------------|-------------------------------------------------|
| `Tab` / `Shift+Tab`| следующая / предыдущая ячейка                   |
| `←` / `→`          | курсор в ячейке; на краю — переход к соседней   |
| `↑` / `↓`          | тот же столбец, соседний сотрудник              |

Первый печатный символ после получения фокуса заменяет всё
содержимое ячейки (как в Excel). Колесико мыши над днями месяца прокручивает их строго по горизонтали, не сбивая список сотрудников.

## Данные и совместная работа

### `tabel_data.json` — общий файл
Хранит список сотрудников, часы за каждый месяц, настройки должностей, подписи и ручные правки. 
Файл можно разместить в общей папке (сетевой диск) — тогда несколько компьютеров смогут работать с одними и теми же данными. Изменения подхватываются автоматически в течение нескольких секунд.

### `local.json` — локальные настройки
Хранит то, что должно быть **разным** на разных машинах:
- тему оформления;
- галочки «В таблицу» и порядок отделов/сотрудников;
- свернутые/развернутые отделы;
- **скрыты или показаны итоги в табеле**.

Это позволяет на одной машине вести табель по одному отделу с одним порядком, а на другой — по другому, пользуясь общим справочником.
Файл хранится **вне** папки программы:
- Windows: `%APPDATA%\TabelApp\local.json`
- Linux:   `~/.config/TabelApp/local.json`

### Резервная копия
Просто скопируйте `tabel_data.json` в надёжное место. 
Файл `local.json` при этом можно не копировать — он привязан к конкретному компьютеру.

## Ограничения одновременной работы

На каждом компьютере табель ведётся **только по одному отделу**.
При попытке включить сотрудника другого отдела программа предупредит и не даст этого сделать, пока не будут сняты галочки «В таблицу» у сотрудников текущего отдела. Активный отдел подсвечивается оранжевым цветом.

---

## Пароль на удаление

Все операции удаления (сотрудники, отделы, должности), а также изменение признаков должностей (Ночные, Сверхурочные, Без вых.) защищены паролем. По умолчанию:
```python
DELETE_PASSWORD = "****"    # config.py
```
Пароль можно изменить в `config.py`.

```

Файл содержит аккуратно сверстанную шапку, подсветку выходных, итоги и подписи. 
Для экспорта требуется библиотека `openpyxl`.
